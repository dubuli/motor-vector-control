# PMSM 电机 dq 轴矢量交互图

这是一个无需后台的单文件 PMSM 矢量控制可视化工具。直接双击 `index.html` 即可运行。

## 当前能力

- 正反转稳态 dq 电压方程及电压、电流双向求解
- 电流限制圆和电压限制椭圆
- MTPA、MTPV 与等转矩线
- 电压、电流矢量拖拽及实时功率指标
- IPMSM、SPMSM、高速和深弱磁可行工况预设

页面以 `index.html` 为唯一运行代码源，避免独立模块与单文件版本产生分叉。

## 模型约定

- `P` 表示极对数。
- dq 电压和电流使用相量峰值。
- 理想 SVPWM 电压上限为 `Umax=Udc/sqrt(3)`。
- MTPV 采用忽略定子电阻的标准稳态轨迹。

## 回归测试

开发时需要 Node.js 18 或更高版本。测试不影响网页直接运行：

```bash
npm test
```

测试覆盖电压/电流正反解、功率平衡、MTPA、MTPV、等转矩线锚点、预设可行性、奇异反解和方向状态同步。
