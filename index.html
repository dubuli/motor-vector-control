📖 说明与数学原理

1. 无需任何后台： 本网页采用纯原生 JavaScript 编写，无需 Python 或 Node.js 后台支持。双击 index.html 即可在浏览器中完美运行。

2. 同图显示与比例映射： 本页的 dq 电压、电流均采用相量峰值约定。直流母线电压通过理想 SVPWM 换算为相电压矢量上限 U_max = U_dc / √3。坐标轴以电流 (A) 为基准物理量，并按 K_v = I_max / U_max 映射电压矢量 U_s 与电压极限圆。

3. 随动计算： 拖拽蓝色 Is 端点时正向求解电压 Us；拖拽橙色 Us 端点时通过矩阵逆运算反向求解电流 (id, iq)。当 Rs = 0 且转速为零时该逆运算没有唯一解，页面会保留原电流并显示提示。

4. 正反转电压方程： ud = Rs·id − ωe·Lq·iq，uq = Rs·iq + ωe·(Ld·id + ψf)，其中 ωe = s·P·2π|N|/60，正转 s = +1、反转 s = −1。反转时交叉耦合项和反电动势项换号，电阻压降项不变。

5. 方向与转矩相互独立： 方向按钮只切换转速和 ωe 的符号，不自动篡改电流。反转时保持正 iq 会进入发电/制动状态；要得到反转电动状态，应令转矩为负（通常对应负 iq）。MTPA/MTPV 显示所选旋转方向对应的电动轨迹；正、负等转矩线则作为完整转矩图谱同时显示，不随转速方向翻转。

6. MTPV 与等转矩线： 深弱磁区采用忽略定子电阻的标准最大转矩/电压轨迹。等转矩线按 ±0.1 / ±0.2 / … / ±1.0 × Tmax 均匀取值，并由 iq = T / [1.5p(ψf + (Ld−Lq)id)] 直接计算。常规 FOC 转矩图只保留 ψf + (Ld−Lq)id > 0 的有效分支，因此正转时上半平面 iq > 0 为正转矩，下半平面 iq < 0 为负转矩。左侧超限尾部在电流圆附近裁剪，右侧按公式延伸到显示边界，并在磁链零点前停止。

7. 图层独立控制： 主图上方可分别显示或隐藏网格、限制边界、MTPA/MTPV、正负等转矩线、Is/Us 矢量及分量投影。图层开关只控制可见性，不改变电机参数、运行点或等转矩线的数学计算范围；坐标轴始终保留。
