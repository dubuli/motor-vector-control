📖 说明与数学原理

1. 无需任何后台： 本网页采用纯原生 JavaScript 编写，无需 Python 或 Node.js 后台支持。双击 index.html 即可在浏览器中完美运行。

2. 同图显示与比例映射： 直流母线电压通过理想 SVPWM 换算为相电压矢量上限 U_max = U_dc / √3。坐标轴以电流 (A) 为基准物理量，并按 K_v = I_max / U_max 映射电压矢量 U_s 与电压极限圆。

3. 随动计算： 拖拽蓝色 Is 端点时正向求解电压 Us；拖拽橙色 Us 端点时通过矩阵逆运算反向求解电流 (id, iq)。

4. 正反转电压方程： ud = Rs·id − ωe·Lq·iq，uq = Rs·iq + ωe·(Ld·id + ψf)，其中 ωe = s·P·2π|N|/60，正转 s = +1、反转 s = −1。反转时交叉耦合项和反电动势项换号，电阻压降项不变。

5. 方向与转矩相互独立： 方向按钮只切换转速和 ωe 的符号，不自动篡改电流。反转时保持正 iq 会进入发电/制动状态；要得到反转电动状态，应令转矩为负（通常对应负 iq）。反转时 MTPA 曲线和转矩等值线会同步镜像到负 q 轴。
